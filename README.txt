MAQUETTE NON OFFICIELLE — EDDY FLORES

1. Décompresser le ZIP.
2. Sur GitHub, créer un dépôt public nommé demo-eddy-flores.
3. Ajouter directement les fichiers index.html, style.css, script.js et les 3 SVG à la RACINE du dépôt (pas le dossier parent).
4. Dans Settings > Pages, sélectionner Deploy from a branch, main, / (root).
5. Adresse attendue : https://teddy85300.github.io/demo-eddy-flores/

Site statique sans dépendances externes, images SVG locales et menu mobile interactif.
Les illustrations sont fictives, non des réalisations. Le contenu est une proposition de maquette non officielle.
Coordonnées et prestations tirées du magazine municipal de Salles (printemps 2025) ; à revalider avant prospection.
